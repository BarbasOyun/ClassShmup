# Rosaure ECS

-Custom ECS in C# for Unity<br>
-Still WIP<br>

## What's an ECS?

-[ECS](https://en.wikipedia.org/wiki/Entity_component_system) stands for Entity Component System<br>
-Allow to manage a lot of Entities in a Simulation<br>
-e.g. Enemies & Projectiles in a Game<br>

## Goals

-Max performance<br>
-Engine agnostic<br>
-Modularity<br>

## Features

-Base ECS that can be implemented by other Systems<br>
-Sub Array indexes<br>
-Define Entity Types / System implementing Rosaure (e.g. Enemy1, Enemy2)<br>
-Define custom data / Entity Type<br>
-Define custom behaviors(logic) / Entity Type<br>
